# 📋 Auto - מערכת אוטומציה לספירת מילים ועדכון אקסל

## סקירה כללית
מערכת אוטומטית שמעבדת קבצי Word (פרוטוקולים משפטיים), סופרת מילים, מעדכנת טבלאות אקסל ומדווחת על סטטוס יומי במייל. בנוסף, מעבדת **הזמנות הקלטה** שמגיעות במייל ומחלצת מהן נתונים לאקסל.

## 🔄 תהליך עבודה לילי

כל לילה בחצות (00:00) המערכת מבצעת:

### Step 0: גיבוי
- מעתיקה את אקסל ירושלים ודרום לתיקיית `backups/`
- שומרת 7 ימים אחורה, מוחקת ישנים יותר
- **אם כונן הדרום לא מחובר — מתריעה בדוח**

### Step 1: עיבוד קבצים (`mail_word_count_prod.py`)
1. סורק את `C:\Users\yoel\OneDrive - Hever\Jerusalem` לקבצי Word
2. לכל קובץ:
   - פותח ב-Word (ברקע), סופר מילים
   - מחלץ **מספר תיק** (Regex, ואם נכשל → LLM)
   - מחלץ **תאריך** (משם הקובץ)
   - מזהה **אזור** (ירושלים/דרום) לפי מילות מפתח
3. מעדכן את האקסל המתאים (**התאמה קשוחה**: תיק + תאריך)
4. מעתיק לכונן F: (היררכיה)
5. מעביר ל-`Done`
6. **מוסיף לתור מיילים** — שולח תמלול לאיש הקשר לפי מחוז

### Step 1.5: חיפוש עמוק (`final_fill_missing.py`)

### Step 1.6: בדיקת תור מיילים
- בודק אם יש מיילים שממתינים בתור מעל יום ומוסיף להתראות

### Step 2: בדיקת חוסרים (`sync_missing_rows_prod.py`)
- סורק קבצים בדיסק ומשווה מול האקסל
- מזהה תיקים שקיימים בדיסק אך חסרים באקסל

### Step 3: דוח מייל
- שולח HTML מעוצב ל-`your_email@example.com`
- כולל: הצלחות, כישלונות, חוסרים, התראות

## 📬 send_district_emails.py — שליחת מיילים לפי מחוז

### מה הוא עושה:
1. אחרי עיבוד תמלול מוצלח — מזהה מחוז לפי תוכן הקובץ
2. שולח מייל עם הקובץ המצורף לאיש הקשר הרלוונטי
3. שולח רק בימי עבודה **ראשון–חמישי 08:00–17:00**
4. אם מחוץ לשעות — מכניס לתור (`logs/pending_emails.json`)
5. **process_email_queue.bat** מריץ שליחה אחת כל ~5 דקות (Task Scheduler)


## ⚠️ כללים עסקיים חשובים

### התאמה קשוחה (Strict Matching)
- עדכון אקסל מתבצע **רק** אם מספר התיק **וגם** התאריך תואמים בדיוק
- אם אין תאריך בקובץ או באקסל → **דילוג** (לא מנחשים)

### עמודת סטטוס
- שם העמודה: `"האם בוטל?"` (ירושלים) או `"בוטל"` (חיפה/דרום)
- אם התיק מסומן כ"בוטל" → **לא מעדכנים**

### פורמטים של מספרי תיק
- **חדש (3 חלקים):** `12345-01-23`, `1234-56-78`, `123-45-67`
- **ישן/עליון (2 חלקים):** `1214-19`, `130-24`
- **לא תקין:** `6657/21` (סלאש — הזנה ידנית בלבד)

### מחוזות
- **ירושלים:** ירושלים, בית שמש, בית המשפט העליון, בגץ
- **דרום:** באר שבע, אשקלון, אשדוד, קריית גת, אילת, נתיבות, דימונה
- **חיפה:** חיפה, נצרת, חדרה, עפולה, עכו, טבריה
